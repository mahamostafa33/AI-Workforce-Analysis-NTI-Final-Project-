# AI Workforce Analysis | NTI Final Project

## Project Overview

This project explores the impact of Artificial Intelligence on the workforce, focusing on AI adoption, task automation, and potential job displacement risks.

## Objectives

* Analyze AI adoption across different industries and job roles.
* Explore the relationship between AI usage and task automation.
* Investigate factors associated with layoff risk.
* Identify how job characteristics may influence AI's impact on employment.

## Tools & Technologies

* Python (Pandas, Matplotlib)
* Power BI
* Jupyter Notebook

## Dataset

The dataset contains information about employees, industries, job roles, AI adoption levels, automation percentages, and layoff risk.

## Project Workflow

1. Data Exploration
2. Data Cleaning using Python
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Dashboard Development using Power BI

## Project Files

* `Untitled6.ipynb`: Python analysis and data preparation.
* `cleaned_ai_impact.csv`: Cleaned dataset.
* `NTI Final Project.pbix`: Interactive Power BI dashboard.
* `NTI Final Project.pptx`: Project presentation.
